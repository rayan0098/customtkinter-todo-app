# 📝 CustomTkinter To-Do App

A simple desktop To-Do application built with **Python** and **CustomTkinter**.

## Features

* Add tasks dynamically
* Mark tasks as completed
* Delete completed tasks
* Dark-mode interface
* Input field clears automatically after adding a task

## Technologies Used

* Python 3
* CustomTkinter

## Run the Project

```bash
pip install customtkinter
python main.py
```

* Managing application state
