CustomTkinter To-Do App

A simple desktop To-Do application built with Python and CustomTkinter.

 Features
Add new tasks dynamically
Mark tasks as completed using checkboxes
Delete all completed tasks
Modern dark-mode interface with CustomTkinter
Input field clears automatically after adding a task
🛠 Technologies Used
Python 3
CustomTkinter

 Run the Project
pip install customtkinter
python main.py
